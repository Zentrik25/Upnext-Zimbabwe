# Design contract

Canonical reference: `reference/approved-flat.html` (approved comparison prototype). Implement functional components rather than copying its demo-only authentication or mock-data logic.

- Flat, premium, information-first layout. No gradients, shadows, glow, glassmorphism, ornamental illustrations, or unnecessary badges.
- Square corners for cards, inputs, modals and buttons; restrained 1px dividers/borders.
- Compact controls typically 34–36px high. Normal/medium font weights; consistent spacing and readable contrast.
- Responsive layouts: mobile first, usable at 320px; keyboard accessible, visible focus, proper labels, semantic landmarks.
- Preserve public search/browse; account gates only on personalised actions.
- Do not add UI frameworks/themes that override these rules.
- Any deliberate visual departure requires user approval before implementation.
