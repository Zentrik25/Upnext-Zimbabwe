# User journeys — DRAFT
## Anonymous discovery
Landing -> search/filter -> results -> detail -> verify source -> external application. No account wall.

## Registration and personalisation
Discover -> choose For You/save -> register/sign in -> verification per approved policy -> optional profile -> explainable feed -> save -> return to source. Clear cancellation/back navigation at every step.

## Editor workflow
Create draft -> enter provenance -> check duplicate -> submit review -> reviewer checks source -> publish -> correct/update -> expire/archive. Rejection must preserve reasons and history.

## Failure states
Offline or failed API, expired link, missing deadline, inaccessible source, duplicate listing, invalid form, session expiry, rate limiting, and empty search all require designed states.
