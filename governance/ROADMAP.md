# Documentation-first roadmap
**D0 Product:** vision, personas, PRD reviewed and approved.
**D1 UX:** journeys, navigation, flat design tokens and screen specifications approved.
**D2 Engineering:** domain schema, architecture, API contracts, security threat model approved.
**D3 Delivery:** test strategy, acceptance criteria, capacity budget and phased build plan approved.
**Build 1:** repository/CI/infrastructure scaffold; **Build 2:** catalogue/editorial API; **Build 3:** public UI; **Build 4:** identity/profiles; **Build 5:** matching/saved; **Build 6:** quality/performance; **Build 7:** staging and explicitly approved production deployment.

Every gate requires evidence and a written approval. No automatic phase advancement.
