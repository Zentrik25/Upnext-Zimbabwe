# UPNEXT design system — APPROVED DIRECTION, tokens DRAFT
**Binding reference:** `reference/approved-flat.html`.

## Non-negotiable
- Flat visual language: square corners (`border-radius: 0` for standard surfaces), no shadows, gradients, glassmorphism or glow.
- Thin 1px dividers and borders; high-quality typography; restrained colour palette.
- Compact, legible controls, generally ~34–36px visual height where accessible touch targets are preserved (e.g. surrounding hit area >=44px on touch).
- No decorative hero clutter, oversized buttons or generic marketing blocks.
- Mobile-first, clear hierarchy, dense but readable listing cards, accessible focus states.

## Token policy
Extract actual typography, colour, spacing and component tokens from the approved reference. Do **not** invent a new palette or font. Record measured tokens in a future `DESIGN_TOKENS.md` after visual audit.

## Components to specify
Navigation, search, category filter, listing card, verified/source badge, deadline indicator, save control, inputs, account forms, profile editor, pagination, empty/error/loading states, modal/dialog, editorial tables.

## Accessibility
WCAG 2.2 AA target, contrast checks, visible keyboard focus, labelled controls, semantic headings, reduced motion and meaningful error feedback.
